# Group Susu Platform - User Guide

## Creating a New Group

Users can create new savings groups in the following ways:

### 1. From the Explore Page
- Navigate to the **Explore** page from the sidebar
- Click the **"Create Group"** button in the top-right corner
- Fill out the group creation form

### 2. Direct Navigation
- Go directly to `/create-group` in your browser
- This will take you to the dedicated group creation page

## Group Creation Process

When creating a group, you'll need to provide:

1. **Group Name** - A descriptive name for your savings group
2. **Contribution Amount** - How much each participant contributes (in SUI)
3. **Contribution Frequency** - How often contributions are made:
   - Daily (1 day)
   - Weekly (7 days)
   - Bi-weekly (14 days)
   - Monthly (30 days)
4. **Maximum Participants** - How many people can join (2-50)

### How It Works

1. **Create the Group** - You become the first participant automatically
2. **Share the Link** - Invite others to join your group
3. **Contributions** - Each round, all participants contribute the set amount
4. **Payouts** - One participant receives the total pool each round
5. **Rotation** - The cycle continues until everyone has received their payout

## Joining an Existing Group

1. Navigate to the **Explore** page
2. Browse available groups or use filters to find one that matches your needs
3. Click on a group to view details
4. Click **"Join Group"** if there are available slots

## Managing Your Groups

Once you're part of a group:

1. View your groups on the **Dashboard**
2. Click on a group to see details
3. If you're the creator, you'll have access to the **Management** page
4. Make contributions when it's time
5. Track your position in the payout rotation

## Key Features

### For Group Creators
- Set contribution amounts and frequencies
- Monitor all participants
- Track contribution status
- View group statistics

### For Group Members
- See your position in the payout queue
- Track contribution deadlines
- View group progress
- Earn reputation points for on-time contributions

## Smart Contract Integration

All groups are managed by smart contracts on the Sui blockchain:
- **Transparent** - All transactions are on-chain
- **Secure** - Funds are held in smart contracts
- **Automated** - Payouts are handled automatically
- **Trustless** - No central authority needed

## Getting Started

1. **Connect Your Wallet** - Use a Sui-compatible wallet
2. **Explore Groups** - Browse existing groups or create your own
3. **Join or Create** - Start saving with others
4. **Build Reputation** - Earn points for consistent participation

## Need Help?

- Check the **Profile** page to view your reputation score
- Visit the **Dashboard** for an overview of your activity
- Use the **Explore** page filters to find groups that match your preferences
