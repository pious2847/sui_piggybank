## 🎯 Key Features to Highlight

### 1. Group Susu (Rotating Savings)
**Innovation**: First decentralized ROSCA implementation on Sui
- ✅ Create custom savings groups
- ✅ Automated round distribution
- ✅ Transparent on-chain tracking
- ✅ Community-based savings

**Demo Flow**:
1. Create a group with 5 members, 1 SUI contribution, monthly frequency
2. Join an existing group
3. Make a contribution
4. Show round distribution
5. Complete a cycle

### 2. Reputation System
**Innovation**: Gamified savings behavior with encrypted history
- ✅ On-chain reputation profiles
- ✅ Point-based reward system
- ✅ Milestone tracking
- ✅ Privacy-preserving with Seal encryption

**Demo Flow**:
1. Create reputation profile
2. Make on-time contribution (+10 points)
3. Complete cycle (+100 points)
4. Show reputation history
5. Reach milestone

- ✅ Images stored on Walrus
- ✅ Metadata on Walrus
- ✅ Shareable profile pages

## 🎬 Demo Script

### Opening (30 seconds)
"Hi! I'm presenting S-Bank, a decentralized savings platform built on Sui blockchain. We're solving the problem of financial exclusion by bringing traditional community savings groups (Susu/ROSCA) on-chain, with added gamification and NFT rewards."

### Problem (30 seconds)
"Billions of people worldwide lack access to formal banking. Traditional savings methods have high barriers, no incentives, and limited transparency. Community savings groups exist but lack trust mechanisms and modern features."

### Solution (1 minute)
"S-Bank provides:
1. Group Susu - rotating savings with automated distribution
2. Piggy Banks - personal savings with no minimum balance
3. Reputation System - track and reward good savings behavior
4. NFT Rewards - achievement NFTs stored on Walrus"

### Demo (2 minutes)
1. **Connect Wallet** - Show Sui wallet connection
2. **Create Group** - Create a savings group
3. **Join & Contribute** - Join group and make contribution
4. **Reputation** - Show reputation points earned
5. **NFT Gallery** - Display achievement NFTs from Walrus
6. **Piggy Bank** - Create and deposit to piggy bank

### Technical (1 minute)
"Built with Move smart contracts on Sui, React frontend, and Walrus for decentralized NFT storage. Features include:
- Type-safe end-to-end
- Optimized caching with React Query
- Comprehensive event system
- Network-aware configuration"

### Impact (30 seconds)
"S-Bank enables financial inclusion for unbanked populations, provides transparent community savings, and gamifies good financial behavior. Real-world applications include diaspora communities, small businesses, and rural savings groups."

### Closing (30 seconds)
"S-Bank is production-ready, fully deployed on testnet, and ready to make a real-world impact. Thank you!"
